# AutoDoc_FullstackProject

У меня в косоли нравящаяся мне версия питона (3.12) вызывается командой "py", поэтому мои команды по работе с виртуальным окружением и по запуску приложения будут все выполняться через эту команду, на других машинах может использоваться другая команда!
ОДНАКО - при установке и запуске виртуального окружения питона, команда может быть какой угодно, так как виртуальное окружение уже установила себе изначально взятый интерпритатор и использует именно его.

### Создание виртуального окружения, активация и установка необходимых бибилиотек:
py -m venv venv
#### Активация в PowerShell
.\venv\Scripts\Activate.ps1
Если возникают ошибки можно сначала изменить политику для разрешения запуска скриптов
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
#### Активация для cmd
venv\Scripts\activate.bat
#### Деактивация виртуального окружения если потребуется
deactivate

После установки и активации виртуального оркужения важно убедиться что окружение действительно запущено, после запуска виртуального окружения в начале строки в командной строке где вводится и выполняется команда должно быть в скобка написано название созданого виртуального окружения, как например у меня (в начале строки появилась в скобках надпись (venv)):
(venv) C:\Users\Tamiron\VSCode\AutoDoc_FullstackProject\backend> 
может быть так что активация прошла но нужно перезапустить терминал, закрыв его и запустив еще раз, ну и конечно окружение может и не запускаться, если вдруг что я фиг его знает как это чинить.

#### Установка всех необходимых пакетов библиотек из файла зависимостей:
После запуска виртуального окружения можно устанавливать все библиотеки, для этого используется утилита "pip"
- Просмотреть установленные пакеты можно командой:
pip list

- Установить необходимые для работы проекта зависимости из requirements.txt можно командой:
pip install -r requirements.txt
- Важно что файл зависимостей с пакетыми находится в корне директории "backend/" поэтому либо перейдите в нужную директорию и там выполните указанную команду, либо выполните эту команду с указанием маршрута до файла requirements.txt, например если находится в корне всего проекта то строка косоли будет выглядеть примерно так:
(venv) C:\Users\Tamiron\VSCode\AutoDoc_FullstackProject>
- А команда для установки из requirements.txt будет выглядеть так:
pip install -r backend/requirements.txt
- может со слешом придется поиграться, либо в право либо в лево, но это я фиг знает тоже.


### Запуск приложения
В первой версии приложения, сейчас оно только отлаживается, было создано тестовое приложение и настроен сервер для его запуска, это только стартовый функционал и в целом это уже первая лабораторная работа по бэкенду.
- Команда для запуска приложения в виде питон-модуля из консоли:
py -m main

В выводе консли должен появится ip-адрес с портом для обращения к API, можно ввести его в браузере и увидеть что ничего не найдено,
но если ввести адрес "/health-api" то ответ от API в браузере отразится на черном фоне в json-формате.
Кроме того, можно перейти на путь "/docs" и увидеть автоматическую документацию с функционалом, которую создал FastAPI, в чем есть одно из его преимуществ.
